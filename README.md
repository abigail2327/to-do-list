# To-Do List App

A simple **Python To-Do List application** that allows users to manage their tasks from the terminal.

## Features

* View tasks
* Add new tasks
* Delete tasks
* Save tasks to a text file
* Load saved tasks when the program starts
* Handles invalid inputs

## How to Run

Make sure Python is installed, then run:

```bash
python3 todo.py
```

## How It Works

The program stores tasks in a `todo_list.txt` file so that tasks are saved even after the program is closed.

## Technologies

* Python
* File handling
* Lists
* Functions
* `try` / `except`

## Example

```text
1. View Tasks
2. Add Task
3. Delete Task
4. Exit

Choose an option:
```
